# Yet Another Personal Site

Freshly made for Hackclub's Stardance program, as I had a nice and pretty personal site while [Dad](https://github.com/yapkke) didn't.

## Design
- Theme: [Catpuccin Latte](https://catppuccin.com/palette/)
- Icons: [Bootstrap Icons](https://icons.getbootstrap.com/) and [Academicons](https://jpswalsh.github.io/academicons/)
- Fonts: [VT323](https://fonts.google.com/specimen/VT323) and [Google Sans Code](https://fonts.google.com/specimen/Google+Sans+Code)
- Background: [CSS Background Generator](https://www.magicpattern.design/tools/css-backgrounds)

## Tech
Just vanilla HTML and CSS, no JS so far...
